# 字段与计算定义

id、bin为字符串，保留前导零；version为正整数。gross、tare为毛重与皮重，unit仅kg或t。净重先换算kg，且毛重不小于皮重。
moisture、impurity为百分数，取值[0,100)，水分超过max_moisture拒收。标准水分必须小于收购上限且低于100。
净粮=净重×(1-杂质/100)，干物质=净粮×(1-水分/100)，折标重=干物质/(1-标准水分/100)。
单价CNY/kg，按未舍入折标重计算总额，再以最大余额法分配分币，余数相同按id升序。全部金额和重量为Decimal，JSON以字符串输出。
同键最高版本采信；同版数值不一致时该键所有行隔离，完全相同则保留最早行。旧版与重复行计入隔离，保证输入行数平衡。
时间仅用于运行清单，保存UTC偏移。空值、哨兵、零分别处理，空文件/仅表头/全空行返回不同原因码。规则参数纳入批次哈希。

## 水分标准分批调整（M8）

调整单独立存于adjustments/adjustment_entries表，runs表中原结算单（原标准水分、原分币结果、复核状态）永不改写。调整单ID由原批次run_id、原/新标准水分与规则版本哈希决定，同参数重跑复用同一单。
发起前置：原结算单复核通过。仅接收new_standard_moisture一个参数；收购上限max_moisture与单价price一律取原单，接口传值忽略；无付款字段与端点。
逐车次确认：先核对两版共同基准 净粮×(1-实测水分)=存档dry_kg，不符抛DRY_MISMATCH，整单置失败并清空半成品分录，原账保留；干物质不变，新折标重= dry_kg/(1-新标准水分/100)，折标差=新折标-原折标。
处理中断后按车次主键跳过已确认分录续跑；INSERT OR IGNORE保证重跑不重复车次或分录。全部车次确认后在末端复用M6最大余额法按新折标重分到分，新总额、原总额与总差额满足 总差额=新总额-原总额=各分录差额之和。
调整证据CSV逐行给出原单、新标准、两版折标、两版金额与差额，末行合计并注明不调收购上限、不做付款。
